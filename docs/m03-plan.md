## 最小闭环

选择技能 → 基础诊断/独立考核/跳级测验 → 服务端签发五个不同题族的新题并保存会话 → 独立作答 → 保存原始结果与证据 → 展示薄弱题族、针对性补习和下一步 → 新题补测通过后解锁下一课。

提示和答案必须经过已鉴权的服务端操作，先保存暴露记录再返回内容。同题不可重复增加证据，跨刷新/会话仍生效；每个题族只保留最近一项有效独立证据。已暴露的本题不计独立证据；补测可用同题族的新问题验证迁移。题库耗尽明确提示，不能靠重复熟题刷通过。
