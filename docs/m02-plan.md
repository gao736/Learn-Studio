# M02：自定义课程最小闭环

用户于 2026-10-06 要求继续 M02，并确认尚未开通百炼，先实现并保留真实验收待办。按已批准的模块计划执行；M03 不开始。

## 交付流程

输入任意主题、学习目标、1—365天、每日5—240分钟和开始日期，默认30天/30分钟 → 范围预览 → 确认并保存草案与月周日时间骨架 → 明确开始生成 → pg-boss 持久任务 → 读取公开资料 → 受控 qwen3.8-flash → 校验并保存课程标题、每周主题和第一课 → 学习、五题作答与保存反馈。失败保存原因并允许重试；输入错误不创建任务。

一个账户每天最多保存一个新课程；失败重试复用原课程。并发创建与预算预占由数据库事务锁保护。多个主题重叠日期的时间相加不得超过本次声明的每日总时间预算；不足时提示调整日期或时间，不默默挤掉已有课程。

首轮仅生成一节正文，未来日程明确为骨架；新内容/实践/复习初始按50%/30%/20%分配，分钟整数合计严格不超预算。复习栏是时间预留，FSRS 属于 M04。首课只评估本次答题，正式解锁属于 M03。

## 实现与安全

- 复用 Better Auth、PostgreSQL RLS、原生表单、CSS设计变量和结果页。
- pg-boss 使用同一数据库；创建生成记录、费用预占与入队在一个事务中提交。只有持久化业务结果才显示成功。
- 默认公开来源为 NASA 等已知主题资料；自定义主题可填写公开资料链接。首轮只抓取可信域名白名单内的 HTTPS 页面，限制重定向、大小、时间和纯文本提取。白名单外明确返回支持范围；私有资料上传留在 M06。
- 资料只是非可信引用内容，不能授权模型访问密钥、数据库或执行工具。模型只能输出固定结构和已有来源ID；不把模型臆造链接显示为核查来源。
- 北京地域 qwen3.8-flash；服务端原生 fetch、JSON校验、60秒超时、最大6000输出token、每课程最多五次尝试。单次预占0.10元，模型预算每月350元，日上限10元。按usage保守估算向上取整到分，实际以百炼账单为准；超时等不确定调用保留预占，不虚报零费用。
- 过期任务可由用户恢复；旧任务不得覆盖新任务的结果。重复提交与费用结算幂等。
- 页面和API都检查账户归属，不向课堂客户端暴露答案键。模拟课程只用于受控测试账户，始终显示模拟标签，不存在公开的模拟成功开关。

## 实施检查顺序

1. 核心规则测试：时间、跨月、输入、材料结构、来源与评分，先失败后实现。
2. 数据迁移与集成测试：并发创建、RLS、真实pg-boss事务入队、限额、幂等结算、失败恢复。
3. 页面与浏览器闭环：真实注册/保存；缺少配置失败；显式模拟测试课的日程、首课、答题、刷新和隔离。
4. M01回归、类型、构建、桌面与手机检查、独立代码审查、记录交付。
