## 演示方法

按照 README 启动。使用 `yourname@example.test` 注册，运行 `node scripts/read-mail.ts yourname@example.test` 读取并打开验证链接。进入示例课，独立选择五题，提交后查看逐题解释；退出、重新登录，查看保存记录。未验证时在登录页可重新发送邮件；忘记密码时通过同一本机收件箱恢复。

重启持久化检查：停止网站请求，运行 `node --env-file=.env.local scripts/check-restart.ts snapshot`；停止本项目数据库并执行 `setup-local.ps1` 重启；运行同一命令的 `verify` 模式。检查只显示数量，不输出账户、答案或密钥。演练期间不要继续新增记录，否则指纹会发生合理变化。
